# WILKREY®
### Digital Studio

Офіційний сайт цифрової студії WILKREY.

Легкий адаптивний сайт, створений на чистих HTML, CSS та JavaScript без важких фреймворків.

### Технології
- HTML5, CSS3, JavaScript
- Web3Forms
- Cloudflare Pages

### Локальний запуск
Відкрийте `index.html` у браузері або скористайтеся VS Code Live Server.

### Публікація

Команда для створення production-збірки:

```bash
bash scripts/build-publish.sh
```

Для Cloudflare Pages:
- Build command: `bash scripts/build-publish.sh`
- Output directory: `dist`
- Branch: `main`

Перед публікацією налаштуйте ключ Web3Forms та перевірте [`чек-лист`](docs/PUBLISH-CHECKLIST.md).
